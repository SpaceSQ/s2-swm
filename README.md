# 4平方米空间场景测试仪

广州智家科技有限公司出品的 PC 软件。本页是千家智客二级域名 [s2-swm.qianjia.com](https://s2-swm.qianjia.com) 的产品介绍，仓库地址为 [SpaceSQ/s2-swm](https://github.com/SpaceSQ/s2-swm)。

这是一台 2 米 × 2 米 × 2.4 米的虚拟空间场景测试仪，用来在电脑上安排光、温度、湿度、风、噪声和气压，查看具身机器人、数字人、智能家居、消费电子和 AI 陪伴产品的反应。实体气候发生器接上之前，可以先完成场景、标准项目和接口约定。画面和读数来自模型推断，不是检测机构的合格证书。

## 软件能做什么

- 在固定舱体里载入数字人或具身机器人，开盖、封舱、运行并保存。
- 按客户任务运行高湿语音、阳台传感器、陪伴产品误用推断、VR 感官负荷和科技馆场景包。
- 进入 20 个地球自然环境。
- 运行 STD-01 至 STD-32 标准检测。电离辐射、霉菌、活体、有害物质和冲击波只做推断。
- 查看十四维张量、补给与碳排放、外观与功能反应。
- 导出 JSON、CSV、MATLAB、SPSS、Origin。
- 按接口控制文件说明无线局域网、MQTT、以太网、USB、RS-485、CAN 和 EtherCAT。有线口是接口约定，安装包不加载实物驱动。
- 用湿实验读数校正温度、湿度、照度、噪声、风速和气压的软件示值。虚拟张量不改写。

仪器母线为 48 V / 500 W。送到物理气候口之前，温度不超过 45℃，二氧化碳不超过 1500 ppm。
